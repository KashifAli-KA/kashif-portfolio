# Kashif Ali: Portfolio

The personal portfolio website of Kashif Ali, a front-end developer from Rahim Yar Khan, Pakistan.

Live site: https://kashif-portfolio-khaki.vercel.app

## What is on the site

- A short introduction, selected work, an about section and contact links
- A case study page for the Garam Chai House demo project
- A downloadable CV
- Motion written in plain CSS, which switches off for visitors who turn animations off
- A social preview image generated by Next.js

## Built with

- Next.js (App Router) and TypeScript
- Tailwind CSS
- Fonts: Plus Jakarta Sans and Newsreader, loaded with next/font
- Deployed on Vercel

## Measured

PageSpeed Insights, mobile, 28 November 2026: Performance 100, Accessibility 100, Best Practices 100, SEO 100.

## Run it on your computer

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
